      Telemetry definitions

      Figures are pseudonymous, aggregate usage signals. They do not contain names, individual journeys, claim rows or payroll details.

      Overview figures

      Unique users
      Pseudonymous installations active during the last three months.
      New and returning users
      New users were first seen in the last 30 days. Returning users are the percentage of active installations first seen before that period.
      Calendar imports
      Successful and failed attempts are shown as a share of all calendar-import attempts. ICS file share is the proportion of successful imports made from a local ICS file rather than a live link.
      Shift activity
      Imported, edited and manually added shifts are compared with the number of claim months created.
      Claims and PDFs
      Distinct claim months created and PDFs saved, counted within each installation and added together.
      Claimed amount and miles
      User-recorded aggregate values for the last three months; they are not audited payroll totals.
      Humber Bridge and email clicks
      The number of times the bridge-information and Email payroll actions were selected.
      Push failures
      Push-notification registrations currently marked as failed.

      Reliability

      Calendar-import failures grouped by their likely cause.

      Network
      The calendar could not be reached or returned a network or HTTP error.
      Timeout
      The calendar request did not finish within the allowed time.
      Invalid calendar
      The retrieved content was empty or was not recognised as readable ICS calendar data.
      File read
      A local ICS file could not be read.
      Unknown
      The import failed but did not match one of the known causes.

      Journey insights

      Each installation appears once at the furthest stage it has reached.

      Opened
      PIER was opened, but no later workflow stage has yet been recorded.
      Calendar
      A calendar was imported, but the user did not progress to shift review.
      Shifts
      The user reached shift review, but did not progress to the claim form.
      Claim
      The user reached or created a claim form, but did not progress to a PDF or the Expense Log.
      PDF
      The user saved a PDF, but has not subsequently opened the Expense Log.
      Log
      The user opened the Expense Log; this is the final recorded stage.

      Installation table

      Each row is a random installation identifier with broad device and feature-use data. Remove excludes it from dashboard totals; Restore includes it again. Delete permanently removes it and prevents a replacement record from that installation.
