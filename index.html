Privacy & cookies

Travel Claims Manager stores claim information locally on this device. A small amount of privacy-preserving usage data is sent to help improve the tool.

What is collected

  • A random installation ID and the date the app was last used
  • App version and broad feature-use counts, such as calendar imports, PDFs created, backups and notification setup
  • Replaceable cumulative totals for claims in the last three months and the current calendar year, used only to show all-user aggregates
  • Optional push-notification subscription details, delivery-failure status and coarse monthly status flags when push is enabled
Local storage, cache and cookies
  • Form details, imported calendar events, signatures, claim rows and the expense log are stored in browser storage on this device
  • A first-party version cookie helps the app recognise its local data format; no advertising or cross-site tracking cookies are used
  • A service-worker cache allows the installed site to open reliably, and IndexedDB holds the random credentials needed for optional push notifications
  • Clearing this site's browser data removes local information, so use the save icon to create a backup first
Calendar fetching

Live calendar fetching uses Travel Claims Manager's built-in Cloudflare Worker. The Worker receives the calendar URL only long enough to retrieve the ICS response and does not store the URL or calendar contents.

Routine use never collects
  • Names, addresses, postcodes or payroll assignment numbers
  • Registration numbers
  • Calendar URLs, tokens or login details
  • Shift names, dates, times or locations
  • Claim rows, mileage, toll costs or individual claim histories
  • Form contents or exported documents
  • Clipboard contents
  • Persistent device fingerprints
  • Screenshots unless deliberately attached after checking them
Feedback and diagnostic data
  • Generated only when something fails or you open Report a bug / give feedback
  • Shown in Review technical details before submission and removable from the report
  • An attached screenshot is resized before upload and should be checked for personal information
  • Reports and screenshots are retained for 90 days and linked using a one-off report ID, not the installation ID

You can turn ordinary usage telemetry off below. Push notifications are controlled separately.

Help & tutorial

  1. Setup: connect a calendar and enter the details used on the claim form. Add a sample signature and optionally configure reminders.
  2. Shifts: choose one or more claim months, then check every imported shift. Study-related events appear in orange and default to “Do not claim”.
  3. Claim form: review each document preview. Tap or click a preview, or use Edit table, to change individual cells. Then sign and save the selected PDFs.
  4. Expense log: use the local log to track submitted claims. Delete an entry if it should no longer be included in the cumulative total.

Backups: use the save icon regularly, particularly before clearing browser data or changing device.

This tool assists with form preparation only. You remain responsible for checking eligibility and accuracy against Trust and payroll rules.
